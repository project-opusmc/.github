# OpusMC

#### OpusMC is the organization behind OPUS, a performance-focused Minecraft client built for competitive play, extensibility, and long-term support across both legacy and modern Minecraft versions.

The project focuses on client performance, rendering, networking, input responsiveness, modular features, and a clean user experience without being tied to a single gamemode or Minecraft version.

## Documentation

Public documentation: [OpusMC Docs](https://github.com/project-opusmc/docs).

The main Opus superproject, Launcher, and Runtime are proprietary. [Opus Optim](https://github.com/project-opusmc/opus-optim) remains open source.
